## Reading these numbers

- **Pre-aggregation is why it scales.** Every dashboard query hits a pre-aggregated, indexed `mart.*` table, so cost grows with the number of *groups* (months, states, categories), not raw orders. 10x the orders is far less than 10x the latency.
- **The cache flattens repeat load.** A warm hit is ~0 ms, so dashboards with many viewers on the same filters pay the DB cost once per TTL.
- **Where it would break first at true scale:** a single-process TTL cache and the in-memory report store don't share across workers — the documented next step is Redis / object storage behind the same interface (see ARCHITECTURE_REVIEW.md §3).
